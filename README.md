# Italian practice

A personal, text-only Italian practice app. The whole app is `index.html`; open it in any browser.

The live copy is a private claude.ai artifact. This repository is where changes are made and reviewed before being republished there. The tag `v7.2` marks the known-good starting version.

See `CLAUDE.md` for how work is done here, and `docs/` for the spec and content guide. To check the content, run `node tools/check-content.js` (needs Node.js). To check that saved progress is safe, run `node tools/test-progress.js` (also needs Playwright).
